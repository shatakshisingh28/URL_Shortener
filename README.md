# 🔗 URL Shortener

A simple URL Shortener that converts long URLs into short, shareable links. Generate a short code for a URL and use it to redirect users to the original destination.

## ✨ Features

* 🔗 **URL Shortening** — Convert long URLs into short codes.
* 🚀 **URL Redirection** — Redirect users to the original URL using the generated short code.
* 📋 **Easy Sharing** — Make long links easier to share and manage.
* ⚡ **Quick Access** — Access the original destination through a short link.

## 🚀 How It Works

1. Enter the original long URL.
2. The application generates a short code for the URL.
3. Share the resulting short link.
4. When someone visits the short link, they are redirected to the original URL.
